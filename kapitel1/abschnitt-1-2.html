1.2Lineare Differenzengleichungen

Bei arithmetischen Folgen kommt in jedem Schritt derselbe Betrag hinzu, bei geometrischen wird mit demselben Faktor multipliziert. Beides sind Spezialfälle der linearen Differenzengleichung xn+1 = a xn + b, zu der auch das Newtonsche Abkühlungsgesetz gehört. Mit veränderlichem Zufluss bn beschreibt sie den Spiegel eines Medikaments.

Abb. 1.11

Arithmetische und geometrische Folge

xn+1 = xn + b  bzw.  xn+1 = a xn

Arithmetische Folgen wachsen oder fallen linear, geometrische exponentiell. Für 0 < a < 1 strebt die geometrische Folge gegen 0, für a > 1 wächst sie über alle Grenzen.

Abb. 1.12

Aktualisierungsfunktionen und Treppendiagramme

f(x) = x + b  bzw.  f(x) = a x

Die Gerade f(x) = x + b ist parallel zur Winkelhalbierenden und schneidet sie nie. Die Gerade f(x) = a x geht durch den Ursprung; ob die Treppe zu ihm hin- oder von ihm wegläuft, hängt von a ab.

# Abb. 1.12: Aktualisierungsfunktionen und Treppendiagramme (Buch, Abschnitt 1.2)
# links: arithmetische Folge f(x) = x + 2 mit x_0 = 20;  rechts: geometrische Folge f(x) = a x mit a = 1.2 und 0.5, x_0 = 1
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots

blau = RGB(0, 0.447, 0.741); hellblau = RGB(0.45, 0.70, 0.90)
rot = RGB(0.64, 0.08, 0.18); hellrot = RGB(0.89, 0.44, 0.49)
function treppe(x)                       # Punkte der Treppe: senkrecht zum Graphen, waagrecht zur Winkelhalbierenden
    px = [x[1]]; py = [0.0]
    for k in 1:length(x) - 1
        append!(px, [x[k], x[k + 1]]); append!(py, [x[k + 1], x[k + 1]])
    end
    return px, py
end

import numpy as np
import matplotlib.pyplot as plt

blau, rot = (0, 0.447, 0.741), (0.64, 0.08, 0.18)

def treppe(ax, f, x0, N, farbe):
    x = [x0]
    for _ in range(N):
        x.append(f(x[-1]))
    px, py = [x[0]], [0]
    for k in range(N):
        px += [x[k], x[k + 1]]; py += [x[k + 1], x[k + 1]]
    ax.plot(px, py, "--", color=farbe)
    return x

ax.set_xlim(18, 33); ax.set_ylim(18, 33); ax.set_xlabel("x"); ax.set_ylabel("f(x)"); ax.legend()

Abb. 1.15

Newtonsches Abkühlungsgesetz

Tn+1 = Tn + α (Tu − Tn)

Für 0 < α ≤ 1 nähert sich die Temperatur monoton der Umgebungstemperatur Tu = 23. Für 1 < α < 2 schwingt sie um Tu, für α = 2 springt sie zwischen zwei Werten, für α > 2 schaukeln sich die Schwingungen auf.

abkuehlung.py Herunterladen 
# Abb. 1.15: Newtonsches Abkühlungsgesetz (Buch, Abschnitt 1.2, Gl. 1.21)
# T_{n+1} = T_n + alpha (T^u - T_n) mit T_0 = 35 und T^u = 23
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots

T0 = 35; Tu = 23; N = 20
n = 0:N
rot = [RGB(0.43, 0.04, 0.12), RGB(0.64, 0.08, 0.18), RGB(0.89, 0.44, 0.49)]; zeichen = [:circle, :rect, :diamond]
bilder = [plot(xlabel = "n", ylabel = "T_n") for _ in 1:4]
for (i, alpha) in enumerate([0.1, 0.2, 0.5, 1.9, 2.0, 2.1])
    T = zeros(N + 1)
    T[1] = T0
    for k in 1:N
        T[k + 1] = T[k] + alpha * (Tu - T[k])
    end
    if i <= 3                            # 0 < alpha < 1: monotone Annäherung an T^u, alle in einem Bild
        plot!(bilder[1], n, T, ls = :dash, marker = zeichen[i], color = rot[i], label = "α = $alpha")
    else                                 # 1 < alpha: Schwingungen
        plot!(bilder[i - 2], n, T, ls = :dash, marker = :circle, color = rot[2], label = "α = $alpha")
        @printf("alpha = %g:  T_19 = %.3f,  T_20 = %.3f\n", alpha, T[20], T[21])
    end
end
for b in bilder
    hline!(b, [Tu], color = :black, label = "")
end
display(plot(bilder..., layout = (2, 2), size = (900, 650)))

# Abb. 1.15: Newtonsches Abkühlungsgesetz (Buch, Abschnitt 1.2, Gl. 1.21)
# T_{n+1} = T_n + alpha (T^u - T_n) mit T_0 = 35 und T^u = 23
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
import numpy as np
import matplotlib.pyplot as plt

T0, Tu, N = 35.0, 23.0, 20
n = np.arange(N + 1)

def abkuehlung(alpha):
    T = np.zeros(N + 1)
    T[0] = T0
    for k in range(N):
        T[k + 1] = T[k] + alpha * (Tu - T[k])
    return T

fig, axs = plt.subplots(2, 2, figsize=(10, 7))
rot = [(0.43, 0.04, 0.12), (0.64, 0.08, 0.18), (0.89, 0.44, 0.49)]
for alpha, c, m in zip([0.1, 0.2, 0.5], rot, "osD"):        # 0 < alpha < 1: monotone Annäherung an T^u
    axs[0, 0].plot(n, abkuehlung(alpha), "--", marker=m, color=c, label=f"α = {alpha}")
for ax, alpha in zip([axs[0, 1], axs[1, 0], axs[1, 1]], [1.9, 2.0, 2.1]):   # 1 < alpha: Schwingungen
    T = abkuehlung(alpha)
    ax.plot(n, T, "o--", color=rot[1], label=f"α = {alpha}")
    print(f"α = {alpha}:  T_19 = {T[19]:.3f},  T_20 = {T[20]:.3f}")
for ax in axs.flat:
    ax.axhline(Tu, color="k", lw=0.8)

# T_{n+1} = T_n + alpha (T^u - T_n) mit T_0 = 35 und T^u = 23

T0 <- 35; Tu <- 23; N <- 20
n <- 0:N
rot <- c(rgb(0.43, 0.04, 0.12), rgb(0.64, 0.08, 0.18), rgb(0.89, 0.44, 0.49)); zeichen <- c(16, 15, 18)
alphas <- c(0.1, 0.2, 0.5, 1.9, 2.0, 2.1)

for (i in 1:6) {
  alpha <- alphas[i]
  T <- numeric(N + 1)
  T[1] <- T0
  for (k in 1:N) T[k + 1] <- T[k] + alpha * (Tu - T[k])
  if (i <= 3) {                          # 0 < alpha < 1: monotone Annäherung an T^u, alle in einem Bild
    if (i == 1) { plot(NULL, xlim = c(0, N), ylim = c(22, 36), xlab = "n", ylab = "T_n"); abline(h = Tu) }
    lines(n, T, type = "o", lty = 2, pch = zeichen[i], col = rot[i])
    if (i == 3) legend("topright", legend = sprintf("alpha = %g", alphas[1:3]), col = rot, pch = zeichen, lty = 2)
  } else {                               # 1 < alpha: Schwingungen
    plot(n, T, type = "o", lty = 2, pch = 16, col = rot[2], xlab = "n", ylab = "T_n", main = sprintf("alpha = %g", alpha))
    abline(h = Tu)
    cat(sprintf("alpha = %g:  T_19 = %.3f,  T_20 = %.3f\n", alpha, T[20], T[21]))
  }
}

Medikamentenspiegel mit täglicher Dosis

xn+1 = a xn + bn,  bn = d alle 24 Stunden
