1.4Stationäre Zustände und Stabilität

Stationäre Zustände sind die Schnittpunkte der Aktualisierungsfunktion mit der Winkelhalbierenden. Ob eine Folge auf einen stationären Zustand zuläuft oder sich von ihm entfernt, entscheidet die Steigung: Für |f′(x*)| < 1 ist er stabil, für |f′(x*)| > 1 instabil. Periodische Punkte findet man als Fixpunkte von fk.

Zu jeder Abbildung des Abschnitts finden Sie das Programm, das sie erzeugt. Ändern Sie Parameter und Startwerte und beobachten Sie, was passiert. Abbildungs- und Gleichungsnummern beziehen sich auf das Buch.

function bisektion(g, lo, hi)
    for _ in 1:100
        m = (lo + hi) / 2

    end
    return (lo + hi) / 2

def fk(x, a, k):                         # k-fache Anwendung von f(y) = a y (1 - y)
    for _ in range(k):
        x = a * x * (1 - x)
    return x

def fixpunkte(a, k):                     # Vorzeichenwechsel von f^k(x) - x suchen, dann halbieren
    x = np.linspace(0, 1, 200001)
    g = fk(x, a, k) - x
    pts = [0.0]
    for i in np.where(np.sign(g[:-1]) != np.sign(g[1:]))[0]:
        lo, hi = x[i], x[i + 1]
        for _ in range(60):
            m = (lo + hi) / 2
            if np.sign(fk(lo, a, k) - lo) == np.sign(fk(m, a, k) - m): lo = m
            else: hi = m
        pts.append((lo + hi) / 2)
    return sorted(set(np.round(pts, 10)))
