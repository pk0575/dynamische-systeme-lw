  • 5.1Vom Zellverbund zur KabelgleichungBenachbarte Herzmuskelzellen sind über Gap Junctions gekoppelt. Lässt man den Abstand Δx der Zellen gegen null gehen, so wird aus dem System gewöhnlicher Differentialgleichungen die Kabelgleichung ∂v/∂t = D ∂2v/∂x2 + … , eine partielle Differentialgleichung. Numerisch löst man sie wieder auf einem Gitter mit dem Euler-Verfahren; dabei muss Δt < Δx2/(2D) gelten. Die Programme zu den Abschnitten 5.2 bis 5.4 zeigen, wie das geht.0 Abb.
  • 5.2Wandernde WellenAuf einer Faser läuft die Erregung als Puls mit fester Form und Geschwindigkeit. Für die Front lässt sich die Geschwindigkeit c = √(D/(2τin)) (1 − 3vs*) exakt angeben; sie wächst mit der Wurzel aus der Kopplung D. Die Programme verwenden D = 0.1 mm2/ms, Δx = 0.1 mm und Δt = 0.01 ms.2 Abb. · Apps
  • 5.3Kreisende ErregungAuf einem Ring läuft die Welle in eine Richtung und trifft nach einem Umlauf auf das Gewebe, das sie selbst erregt hat. Ist der Ring kürzer als etwa die Wellenlänge, so ist dieses Gewebe noch refraktär, und die Erregung erlischt.1 Abb.
  • 5.4Spiralwellen in der EbeneIn einer Gewebeschicht tritt an die Stelle der zweiten Ableitung der Laplace-Operator Δv. Ein zweiter Reiz in teilweise refraktärem Gewebe erzeugt eine Spiralwelle, die das Gewebe ohne weitere Reize immer wieder erregt – ein Modell für eine Kammertachykardie.2 Abb. · Apps
  • 5.5Vom Gewebe zum ganzen HerzenIm Herzen breitet sich die Erregung dreidimensional aus, schneller längs der Fasern, deren Richtung sich durch die Herzwand dreht. Heutige Herzmodelle verbinden detaillierte Zellmodelle, das Bidomain-Modell und patientenspezifische Geometrien; die Simulation in Abbildung 5.7 des Buchs entstand mit der frei verfügbaren Software openCARP auf einem Laptop.0 Abb.
