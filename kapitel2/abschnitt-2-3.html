2.3Eigenwerte und Langzeitverhalten

Die Lösung xn = An x0 lässt sich mit Eigenwerten und Eigenvektoren zerlegen. Auf lange Sicht setzt sich der betragsgrößte, dominante Eigenwert λ1 durch: Er bestimmt, ob das System wächst, schrumpft oder zur Ruhe kommt, und sein Eigenvektor gibt die Verteilung auf die Komponenten an.

Abb. 2.10

Quotient aufeinanderfolgender Fibonacci-Zahlen

A = (0 1; 1 1),  λ1 = (1 + √5)/2

Der Quotient en+1/en pendelt sich beim dominanten Eigenwert ein, dem goldenen Schnitt 1.618… Das Programm berechnet die Eigenwerte mit eigvals bzw. eig.

# Abb. 2.10: Quotient aufeinanderfolgender Fibonacci-Zahlen (Buch, Abschnitt 2.3, Gl. 2.15)
# System j_{n+1} = e_n, e_{n+1} = e_n + j_n; der Quotient e_{n+1}/e_n strebt gegen den dominanten Eigenwert (goldener Schnitt)
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots, LinearAlgebra

A = [0 1;
     1 1]
x = [1, 0]                               # (j_0, e_0): ein junges Paar
e = [x[2]]
for k in 1:16
    global x = A * x
    push!(e, x[2])
end
q = e[3:end] ./ e[2:end-1]
println("Eigenwerte von A: ", join([@sprintf("%.6f", l) for l in sort(eigvals(A))], "  "))
println("e_{n+1}/e_n: ", join([@sprintf("%.6f", v) for v in q[end-3:end]], "  "), "   goldener Schnitt: ", @sprintf("%.6f", (1 + sqrt(5)) / 2))

p = plot(1:length(q), q, ls = :dash, marker = :circle, color = RGB(0.64, 0.08, 0.18), label = "e_{n+1}/e_n", xlabel = "n")
hline!(p, [(1 + sqrt(5)) / 2], ls = :dash, color = :black, label = "λ₁ = 1.618")
display(p)

Abb. 2.12

Stabile Altersverteilung

b2 = 5:  λ1 ≈ 1.0157

Bekommt auch die zweite Altersklasse Nachwuchs, gibt es einen dominanten Eigenwert. Die Anteile der Klassen nähern sich seinem Eigenvektor, der stabilen Altersverteilung, und die Population wächst langsam.

leslie_anteile.py Herunterladen 
# Abb. 2.12: stabile Altersverteilung im Leslie-Modell (Buch, Abschnitt 2.3, Gl. 2.17)
# L mit b_2 = 5: die Anteile der Klassen nähern sich dem Eigenvektor v_1 zum dominanten Eigenwert lambda_1
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots, LinearAlgebra

L = [0   5   9;
     0.1 0   0;
     0   0.6 0]
w, Vec = eigen(L)
i1 = argmax(abs.(w))
v1 = real.(Vec[:, i1]); v1 = v1 ./ sum(v1)
@printf("dominanter Eigenwert lambda_1 = %.4f\n", real(w[i1]))
@printf("stabile Altersverteilung v_1 = (%.3f, %.3f, %.3f)\n", v1...)

N = 30
X = zeros(3, N + 1); X[:, 1] = [0, 0, 1000]
for k in 1:N
    X[:, k + 1] = L * X[:, k]
end
P = X ./ sum(X, dims = 1)                # Anteile der Klassen
farben = [RGB(0.43, 0.04, 0.12), RGB(0.89, 0.44, 0.49), RGB(0.64, 0.08, 0.18)]; zeichen = [:circle, :rect, :diamond]
p = plot(xlabel = "n", ylabel = "Anteil der Klasse")
for i in 1:3
    plot!(p, 0:N, P[i, :], marker = zeichen[i], color = farben[i], label = "Klasse $i")
    hline!(p, [v1[i]], ls = :dash, color = farben[i], label = "")
end
display(p)

Abb. 2.13

Dominanter Eigenwert in Abhängigkeit von b2

R = b1 + s1 b2 + s1 s2 b3

λ1 überschreitet 1 genau dort, wo die Zahl R der Nachkommen eines Neugeborenen 1 überschreitet, bei b2 = 4.6.

leslie_eigenwert.py Herunterladen 
# Abb. 2.13: dominanter Eigenwert des Leslie-Modells in Abhängigkeit von b_2 (Buch, Abschnitt 2.3, Gl. 2.19)
# b_1 = 0, b_3 = 9, s_1 = 0.1, s_2 = 0.6; bei R = b_1 + s_1 b_2 + s_1 s_2 b_3 = 1, also b_2 = 4.6, ist lambda_1 = 1
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots, LinearAlgebra

b2 = range(0, 10, length = 201)
lam = [maximum(abs.(eigvals([0 b 9; 0.1 0 0; 0 0.6 0]))) for b in b2]
@printf("b_2 mit R = 1: %.2f\n", (1 - 0.54) / 0.1)
@printf("lambda_1 bei b_2 = 4.6: %.6f\n", maximum(abs.(eigvals([0 4.6 9; 0.1 0 0; 0 0.6 0]))))

p = plot(b2, lam, color = RGB(0, 0.447, 0.741), lw = 2, legend = false, xlabel = "b_2", ylabel = "λ₁")
hline!(p, [1], color = :black); plot!(p, [4.6, 4.6], [0.75, 1.2], ls = :dot, color = :black)
display(p)
