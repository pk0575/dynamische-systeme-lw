2.4Nichtlineare Systeme: SIR-Modell

Im SIR-Modell wird eine Bevölkerung in Empfängliche (S), Infizierte (I) und Genesene (R) eingeteilt. Neuinfektionen entstehen bei Kontakten zwischen S und I, daher das Produkt β Sn In: Das System ist nichtlinear. Ob sich eine Krankheit hält, entscheidet die Basisreproduktionszahl R0.

Zu jeder Abbildung des Abschnitts finden Sie das Programm, das sie erzeugt. Ändern Sie Parameter und Startwerte und beobachten Sie, was passiert. Abbildungs- und Gleichungsnummern beziehen sich auf das Buch.

Abb. 2.15

SIR-Modell, Szenarien A und B

Sn+1 = Sn − β Sn In + α N − α Sn,  In+1 = In + β Sn In − (γ + α) In

In Szenario A (R0 = 0.6) verschwindet die Krankheit trotz 30 000 Infizierter am Anfang. In Szenario B (R0 = 3.8) genügt ein einziger Infizierter für eine Epidemie, nach der sich ein endemischer Zustand einstellt.

# Abb. 2.15: SIR-Modell, Szenarien A und B (Buch, Abschnitt 2.4, Gl. 2.21)
# S_{n+1} = S_n - beta S_n I_n + alpha N - alpha S_n,  I_{n+1} = I_n + beta S_n I_n - (gamma + alpha) I_n,  R_{n+1} = R_n + gamma I_n - alpha R_n
# N = 100000, alpha = gamma = 0.1;  A: beta = 1.2e-6, S_0 = 70000, I_0 = 30000;  B: beta = 7.6e-6, S_0 = 99999, I_0 = 1
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots, LinearAlgebra
N = 100000; alpha = 0.1; gamma = 0.1

farben = [RGB(0.43, 0.04, 0.12), RGB(0.89, 0.44, 0.49), RGB(0.64, 0.08, 0.18)]; zeichen = [:circle, :rect, :diamond]
lab = ["S_n", "I_n", "R_n"]
bilder = []
for (name, beta, S0, I0, M) in [("A", 1.2e-6, 70000, 30000, 60), ("B", 7.6e-6, 99999, 1, 80)]
    X = zeros(3, M + 1)                  # Zeilen: S, I, R
    X[:, 1] = [S0, I0, N - S0 - I0]
    for k in 1:M
        S, I, R = X[:, k]
        X[:, k + 1] = [S - beta * S * I + alpha * N - alpha * S,
                       I + beta * S * I - (gamma + alpha) * I,
                       R + gamma * I - alpha * R]
    end
    R0 = beta * N / (gamma + alpha)      # Basisreproduktionszahl
    @printf("Szenario %s: R_0 = %.1f,  (S, I, R) nach %d Schritten = (%.0f, %.0f, %.0f)\n", name, R0, M, X[:, end]...)
    for z in 1:3
        push!(bilder, plot(0:M, X[z, :], ls = :dash, marker = zeichen[z], ms = 2, color = farben[z], label = lab[z],
                           title = z == 1 ? "Szenario $name, β = $beta" : ""))
    end
end
display(plot(bilder[[1, 4, 2, 5, 3, 6]]..., layout = (3, 2), size = (900, 650)))

# N = 100000, alpha = gamma = 0.1;  A: beta = 1.2e-6, S_0 = 70000, I_0 = 30000;  B: beta = 7.6e-6, S_0 = 99999, I_0 = 1

import numpy as np
import matplotlib.pyplot as plt

N, alpha, gamma = 100000, 0.1, 0.1

def sir(beta, S0, I0, schritte):
    S, I, R = np.zeros(schritte + 1), np.zeros(schritte + 1), np.zeros(schritte + 1)
    S[0], I[0], R[0] = S0, I0, N - S0 - I0
    for n in range(schritte):
        S[n + 1] = S[n] - beta * S[n] * I[n] + alpha * N - alpha * S[n]
        I[n + 1] = I[n] + beta * S[n] * I[n] - (gamma + alpha) * I[n]
        R[n + 1] = R[n] + gamma * I[n] - alpha * R[n]
    return S, I, R

farben = [(0.43, 0.04, 0.12), (0.89, 0.44, 0.49), (0.64, 0.08, 0.18)]
for spalte, (name, beta, S0, I0, schritte) in enumerate([("A", 1.2e-6, 70000, 30000, 60), ("B", 7.6e-6, 99999, 1, 80)]):
    S, I, R = sir(beta, S0, I0, schritte)
    R0 = beta * N / (gamma + alpha)                     # Basisreproduktionszahl

    for zeile, (X, lab, m) in enumerate(zip([S, I, R], ["S_n", "I_n", "R_n"], "osD")):

    axs[0, spalte].set_title(f"Szenario {name}, β = {beta:g}")
    axs[2, spalte].set_xlabel("n")
plt.tight_layout()
plt.show()

Abb. 2.16

Szenario B in der Phasenebene

S* = N/R0,  I* = α (N − S*)/(γ + α)

Die Zustände (Sn, In) laufen vom krankheitsfreien Zustand (N, 0) weg und in einer Spirale auf den endemischen Zustand zu (Kreuz).

Abb. 2.17

Stationäre Werte I* in Abhängigkeit von R0

R0 = β N/(γ + α)

Bei R0 = 1 kreuzen sich die beiden stationären Zustände und tauschen ihre Stabilität. Durchgezogen: stabil, gestrichelt: instabil.

Anfangsphase und Neuinfektionen

In ≈ λn I0,  λ = 1 + (γ + α)(R0 − 1)

Solange fast alle empfänglich sind, wächst die Zahl der Infizierten geometrisch (links, logarithmische Achse). Rechts: Je größer R0, desto früher und höher ist die Spitze der Neuinfektionen.

using Printf, Plots, LinearAlgebra
N = 100000; alpha = 0.1; gamma = 0.1

function sir(beta, M)                    # S_n und I_n für I_0 = 1
    S = zeros(M + 1); I = zeros(M + 1); S[1] = N - 1; I[1] = 1
    for k in 1:M

end
