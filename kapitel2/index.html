  • 2.1Beispiele: Fibonacci und Räuber-BeuteViele Vorgänge lassen sich nur mit mehreren Größen zugleich beschreiben: junge und erwachsene Hasenpaare, Beute und Räuber. Jede Größe erhält eine eigene Rekursionsvorschrift, und die Vorschriften hängen voneinander ab. So entsteht ein System von Differenzengleichungen.3 Abb. · Apps
  • 2.2Matrix-ModelleSind alle Rekursionsvorschriften linear, schreibt man das System kompakt als xn+1 = A xn mit einer Matrix A und dem Zustandsvektor xn. Ein Schritt ist dann eine Multiplikation Matrix mal Vektor. Beispiele sind ein Krankheitsverlauf mit drei Gruppen und das Leslie-Modell für Altersklassen.2 Abb. · Apps
  • 2.3Eigenwerte und LangzeitverhaltenDie Lösung xn = An x0 lässt sich mit Eigenwerten und Eigenvektoren zerlegen. Auf lange Sicht setzt sich der betragsgrößte, dominante Eigenwert λ1 durch: Er bestimmt, ob das System wächst, schrumpft oder zur Ruhe kommt, und sein Eigenvektor gibt die Verteilung auf die Komponenten an.4 Abb. · Apps
  • 2.4Nichtlineare Systeme: SIR-ModellIm SIR-Modell wird eine Bevölkerung in Empfängliche (S), Infizierte (I) und Genesene (R) eingeteilt. Neuinfektionen entstehen bei Kontakten zwischen S und I, daher das Produkt β Sn In: Das System ist nichtlinear. Ob sich eine Krankheit hält, entscheidet die Basisreproduktionszahl R0.4 Abb. · Apps
  • 2.5Vertiefung: Ausbreitung des AktionspotentialsMit zwei Variablen pro Zelle beschreibt das Chialvo-Modell ein Aktionspotential. Koppelt man viele solcher Zellen auf einem Ring oder in einer Ebene, breitet sich die Erregung als Welle aus. Eine ungünstig getimte zweite Anregung oder eine kurze Blockade kann eine kreisende Erregung auslösen, ein Modell für Reentry-Rhythmusstörungen.6 Abb.
