2.5Vertiefung: Ausbreitung des Aktionspotentials

Mit zwei Variablen pro Zelle beschreibt das Chialvo-Modell ein Aktionspotential. Koppelt man viele solcher Zellen auf einem Ring oder in einer Ebene, breitet sich die Erregung als Welle aus. Eine ungünstig getimte zweite Anregung oder eine kurze Blockade kann eine kreisende Erregung auslösen, ein Modell für Reentry-Rhythmusstörungen.

Zu jeder Abbildung des Abschnitts finden Sie das Programm, das sie erzeugt. Ändern Sie Parameter und Startwerte und beobachten Sie, was passiert. Abbildungs- und Gleichungsnummern beziehen sich auf das Buch.

Abb. 2.19

Aktionspotentiale im Chialvo-Modell

y1,n+1 = y1,n2 ey2,n − y1,n + k,  y2,n+1 = a y2,n − b y1,n + c

Für b = 0.26 entstehen regelmäßige Aktionspotentiale, für b = 0.18 unregelmäßige mit frühen Nachdepolarisationen. Das Programm zählt die Ausschläge über 1.

# Abb. 2.19: Aktionspotentiale im Chialvo-Modell (Buch, Abschnitt 2.5, Gl. 2.33)
# y1_{n+1} = y1_n^2 exp(y2_n - y1_n) + k,  y2_{n+1} = a y2_n - b y1_n + c  mit a = 0.89, c = 0.28, k = 0.03
# links b = 0.26 (regelmäßig), rechts b = 0.18 (chaotisch, frühe Nachdepolarisationen); oben y1, unten y2
# (c) 2026 Philipp Kügler · Programm zum Buch „Dynamische Systeme in den Lebenswissenschaften“ · MIT-Lizenz (siehe LICENSE)
using Printf, Plots, LinearAlgebra

a = 0.89; c = 0.28; k = 0.03; N = 150
bilder = []
for b in (0.26, 0.18)
    y1 = zeros(N + 1); y2 = zeros(N + 1)
    y1[1] = 0.2; y2[1] = c / (1 - a)
    for j in 1:N
        y1[j + 1] = y1[j]^2 * exp(y2[j] - y1[j]) + k
        y2[j + 1] = a * y2[j] - b * y1[j] + c
    end
    ap = sum((y1[2:end] .> 1) .& (y1[1:end-1] .<= 1))     # Anzahl der Ausschläge über 1
    @printf("b = %g: %d Aktionspotentiale in %d Schritten, max y1 = %.2f\n", b, ap, N, maximum(y1))
    push!(bilder, plot(0:N, y1, ls = :dash, marker = :circle, ms = 2, color = RGB(0.64, 0.08, 0.18), legend = false, title = "b = $b", ylabel = "y_1,n"))
    push!(bilder, plot(0:N, y2, ls = :dash, marker = :circle, ms = 2, color = RGB(0.89, 0.44, 0.49), legend = false, xlabel = "n", ylabel = "y_2,n"))
end

Abb. 2.20

Ausbreitung auf einem Ring

y1,i,n+1 = (1 − d) f(yi,n) + d/2 (f(yi+1,n) + f(yi−1,n))

Von Zelle 1 laufen zwei Wellen in entgegengesetzte Richtungen um den Ring und löschen sich aus, wenn sie aufeinandertreffen. Die Ausgabe listet die erregten Zellen (y1 > 1).

y1r = 0.2; y2r = c / (1 - a)

    global y1r, y2r = f1(y1r, y2r), a * y2r - b * y1r + c
end

function ring(n_stoer = -1; Z = 50, schritte = 201)
    # Ring aus Z Zellen; Zelle 1 startet erregt (0.3), optional zweite Anregung der Zelle 36 nach n_stoer Schritten
    Y1 = fill(y1r, schritte + 1, Z); Y2 = fill(y2r, schritte + 1, Z)   # Zeile n+1 = Zeitschritt n
    Y1[1, 1] = 0.3
    rechts = [2:Z; 1]; links = [Z; 1:Z-1]                            # Nachbarn auf dem Ring
    for n in 0:schritte-1
        F = f1.(Y1[n + 1, :], Y2[n + 1, :])
        Y1[n + 2, :] = (1 - d) .* F .+ d / 2 .* (F[rechts] .+ F[links])
        Y2[n + 2, :] = a .* Y2[n + 1, :] .- b .* Y1[n + 1, :] .+ c
        n + 1 == n_stoer && (Y1[n + 2, 36] = 0.3)                     # zweite Anregung der Zelle 36
    end
    return Y1
end

def ring(n_stoer=None, Z=50, schritte=201):

    Y1 = np.full((schritte + 1, Z), y1r); Y2 = np.full((schritte + 1, Z), y2r)

    rechts, links = np.roll(np.arange(Z), -1), np.roll(np.arange(Z), 1)    # Nachbarn auf dem Ring

        if n_stoer is not None and n + 1 == n_stoer:

    return Y1
