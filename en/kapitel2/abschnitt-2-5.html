2.5In Depth: Propagation of the Action Potential

With two variables per cell, the Chialvo model describes an action potential. If many such cells are coupled on a ring or in a plane, the excitation spreads as a wave. A badly timed second stimulation or a brief block can trigger a circulating excitation, a model for reentry arrhythmias.

For each figure of the section you will find the program that produces it. Change parameters and initial values and observe what happens. Figure and equation numbers refer to the book.

Fig. 2.19

Action potentials in the Chialvo model

y1,n+1 = y1,n2 ey2,n − y1,n + k,  y2,n+1 = a y2,n − b y1,n + c

For b = 0.26 regular action potentials arise, for b = 0.18 irregular ones with early afterdepolarizations. The program counts the excursions above 1.

# Fig. 2.19: Action potentials in the Chialvo model (book, Section 2.5, Eq. 2.33)
# y1_{n+1} = y1_n^2 exp(y2_n - y1_n) + k,  y2_{n+1} = a y2_n - b y1_n + c  with a = 0.89, c = 0.28, k = 0.03
# left b = 0.26 (regular), right b = 0.18 (chaotic, early afterdepolarizations); top y1, bottom y2
# (c) 2026 Philipp Kügler · Program for the book "Dynamical Systems in the Life Sciences" · MIT License (see LICENSE)
using Printf, Plots, LinearAlgebra

a = 0.89; c = 0.28; k = 0.03; N = 150
bilder = []
for b in (0.26, 0.18)
    y1 = zeros(N + 1); y2 = zeros(N + 1)
    y1[1] = 0.2; y2[1] = c / (1 - a)
    for j in 1:N
        y1[j + 1] = y1[j]^2 * exp(y2[j] - y1[j]) + k
        y2[j + 1] = a * y2[j] - b * y1[j] + c
    end
    ap = sum((y1[2:end] .> 1) .& (y1[1:end-1] .<= 1))     # number of excursions above 1
    @printf("b = %g: %d action potentials in %d steps, max y1 = %.2f\n", b, ap, N, maximum(y1))
    push!(bilder, plot(0:N, y1, ls = :dash, marker = :circle, ms = 2, color = RGB(0.64, 0.08, 0.18), legend = false, title = "b = $b", ylabel = "y_1,n"))
    push!(bilder, plot(0:N, y2, ls = :dash, marker = :circle, ms = 2, color = RGB(0.89, 0.44, 0.49), legend = false, xlabel = "n", ylabel = "y_2,n"))
end

Fig. 2.20

Propagation on a ring

y1,i,n+1 = (1 − d) f(yi,n) + d/2 (f(yi+1,n) + f(yi−1,n))

From cell 1 two waves travel around the ring in opposite directions and annihilate each other when they meet. The output lists the excited cells (y1 > 1).

function ring(n_stoer = -1; Z = 50, schritte = 201)
    # ring of Z cells; cell 1 starts excited (0.3), optionally a second stimulation of cell 36 after n_stoer steps
    Y1 = fill(y1r, schritte + 1, Z); Y2 = fill(y2r, schritte + 1, Z)   # row n+1 = time step n
    Y1[1, 1] = 0.3
    rechts = [2:Z; 1]; links = [Z; 1:Z-1]                            # neighbors on the ring
    for n in 0:schritte-1
        F = f1.(Y1[n + 1, :], Y2[n + 1, :])
        Y1[n + 2, :] = (1 - d) .* F .+ d / 2 .* (F[rechts] .+ F[links])
        Y2[n + 2, :] = a .* Y2[n + 1, :] .- b .* Y1[n + 1, :] .+ c
        n + 1 == n_stoer && (Y1[n + 2, 36] = 0.3)                     # second stimulation of cell 36
    end
    return Y1
end

def ring(n_stoer=None, Z=50, schritte=201):
    """Ring of Z cells; cell 1 starts excited (0.3), optionally a second stimulation of cell 36 after n_stoer steps."""
    Y1 = np.full((schritte + 1, Z), y1r); Y2 = np.full((schritte + 1, Z), y2r)
    Y1[0, 0] = 0.3
    rechts, links = np.roll(np.arange(Z), -1), np.roll(np.arange(Z), 1)    # neighbors on the ring

        Y1[n + 1] = (1 - d) * F + d / 2 * (F[rechts] + F[links])
        Y2[n + 1] = a * Y2[n] - b * Y1[n] + c
        if n_stoer is not None and n + 1 == n_stoer:
            Y1[n + 1, 35] = 0.3                                            # Cell 36
    return Y1

Second stimulation of cell 36

a, b, c, k, d = 0.89, 0.6, 0.28, 0.02, 0.4
f1 = lambda y1, y2: y1**2 * np.exp(y2 - y1) + k
y1r, y2r = 0.2, c / (1 - a)
for _ in range(180):                                   # resting state of a single cell
    y1r, y2r = f1(y1r, y2r), a * y2r - b * y1r + c

def ebene(blockade, schritte, Z=100):
    """Z x Z cells, no-flux boundary; left edge (i = 1) starts excited. List of the states y1 for n = 0, 1, 2, ..."""
    Y1 = np.full((Z, Z), y1r); Y2 = np.full((Z, Z), y2r); Y1[0, :] = 0.3
    vor, zur = np.r_[1:Z, Z - 1], np.r_[0, 0:Z - 1]     # neighbor indices, at the boundary the cell itself
    zustaende = [Y1.copy()]
    for n in range(1, schritte + 1):
        D = np.full((Z, Z), d)
        if blockade and 50 <= n <= 52:
            D[27:30, 0:50] = 0                            # block in the region [28, 30] x [1, 50]
        F = f1(Y1, Y2)
        Y1neu = (1 - D) * F + D / 4 * (F[vor, :] + F[zur, :] + F[:, vor] + F[:, zur])
        Y2 = a * Y2 - b * Y1 + c
        Y1 = Y1neu
        zustaende.append(Y1.copy())
    return zustaende
