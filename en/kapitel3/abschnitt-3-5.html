3.5In Depth: Excitability of Heart Cells

The Mitchell–Schaeffer model describes the action potential of a cardiac muscle cell with a differential equation for the membrane potential v. If the channel variable h is held fixed, it has a resting state, a threshold, and an excited state. If h is allowed to change slowly, a complete action potential arises, and its duration and the restitution curve can be computed. The programs use Euler's method with h = 0.01 ms.

For each figure of the section you will find the program that produces it. Change parameters and initial values and observe what happens. Figure and equation numbers refer to the book.

# dv/dt = h v^2 (1 - v)/tin - v/tout + J(t) with fixed h = 1; left f(v) with rest, threshold, and excited state,
# right response to a 2 ms stimulus below (J = 0.02) and above (J = 0.04) the threshold
# (c) 2026 Philipp Kügler · Program for the book "Dynamical Systems in the Life Sciences" · MIT License (see LICENSE)
using Printf, Plots
tin = 0.3; tout = 6.0; topen = 100.0; tclose = 115.0; vgate = 0.13   # parameters in ms
hc = 4 * tin / tout

function simuliere(T, reize; J = 0.2, dauer = 2.0, dt = 0.01, h_fest = false)
    # Euler's method for the Mitchell-Schaeffer model; stimulus current J for 'dauer' ms from each time in 'reize'
    N = round(Int, T / dt); t = dt .* (0:N)
    Jt = zeros(N + 1)
    for s in reize
        Jt[(t .>= s - 1e-9) .& (t .< s + dauer - 1e-9)] .= J
    end
    v = zeros(N + 1); h = ones(N + 1)
    for n in 1:N
        dv = h[n] * v[n]^2 * (1 - v[n]) / tin - v[n] / tout + Jt[n]
        dh = h_fest ? 0.0 : (v[n] < vgate ? (1 - h[n]) / topen : -h[n] / tclose)
        v[n + 1] = v[n] + dt * dv; h[n + 1] = h[n] + dt * dh
    end
    return t, v, h
end

def simuliere(T, reize, J=0.2, dauer=2.0, dt=0.01, h_fest=None):
    """Euler method for the Mitchell-Schaeffer model; stimulus current J for 'dauer' ms from each time in 'reize'."""
    N = int(round(T / dt)); t = dt * np.arange(N + 1)
    Jt = np.zeros(N + 1)
    for s in reize:
        Jt[(t >= s - 1e-9) & (t < s + dauer - 1e-9)] = J
    v = np.zeros(N + 1); h = np.ones(N + 1)
    for n in range(N):
        dv = h[n] * v[n]**2 * (1 - v[n]) / tin - v[n] / tout + Jt[n]
        if h_fest is not None: dh = 0.0
        elif v[n] < vgate: dh = (1 - h[n]) / topen
        else: dh = -h[n] / tclose
        v[n + 1] = v[n] + dt * dv; h[n + 1] = h[n] + dt * dh
    return t, v, h

def durchgaenge(t, v, schwelle=0.1):
    """times at which v crosses the threshold upward or downward (start and end of an action potential)."""
    i = np.where(np.diff(np.sign(v - schwelle)) != 0)[0]
    return t[i]
