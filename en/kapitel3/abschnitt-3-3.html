3.3Steady States and Stability

An autonomous differential equation dx/dt = f(x) is steady where f(x*) = 0. Whether the solutions run toward x* or away from it is shown by the phase line, and computationally by the sign of f′(x*). If f depends on a parameter, the bifurcation diagram describes how the steady states change – for instance when a stock is fished or in the gene switch of the lac operon.

For each figure of the section you will find the program that produces it. Change parameters and initial values and observe what happens. Figure and equation numbers refer to the book.

Fig. 3.14

Phase line of the logistic model

f(x) = r (1 − x/K) x,  f′(0) = r > 0,  f′(K) = −r < 0

Where f is positive, x grows; where f is negative, x decreases. Therefore x* = K is stable (filled) and x* = 0 is unstable (open).

f(x) = r * (1 - x / K) * x

scatter!(p, [0], [0], color = :white, msc = :black, ms = 7, label = ""); scatter!(p, [K], [0], color = :black, ms = 7, label = "")
for xs in (0, K)

Fig. 3.16

Fish stock with harvesting rate

dx/dt = r (1 − x/K) x − h x

As long as the harvesting rate h is smaller than r, a stock x* = K (1 − h/r) persists. At h = r the two steady states exchange their stability.

Fig. 3.17

Fish stock with a fixed catch quota

dx/dt = r (1 − x/K) x − q

With a fixed quota, the stable and the unstable state merge at q = rK/4 and disappear. A larger quota leads to the collapse of the stock.

# Fig. 3.17: Harvesting with a fixed catch quota (book, Section 3.3)
# dx/dt = r (1 - x/K) x - q with r = 0.5, K = 100;  steady at x* = K/2 (1 ± sqrt(1 - 4q/(rK))) as long as q <= rK/4 = 12.5
# (c) 2026 Philipp Kügler · Program for the book "Dynamical Systems in the Life Sciences" · MIT License (see LICENSE)
using Printf, Plots

r = 0.5; K = 100
gruen = RGB(0, 0.39, 0)
x = range(0, 100, length = 300)
p1 = plot(x, r .* x .* (1 .- x ./ K), color = RGB(0, 0.447, 0.741), lw = 2.5, label = "Growth", xlabel = "x (1000 t)",
          title = "Growth r x (1 - x/K) and catch q", titlefontsize = 10)
for (q, stil) in zip([8, 12.5, 16], [:solid, :dash, :dot])
    hline!(p1, [q], ls = stil, color = RGB(0.64, 0.08, 0.18), lw = 2, label = "q = $q")
end
q = range(0, 12.5, length = 300)
w = sqrt.(max.(0, 1 .- 4 .* q ./ (r * K)))     # max(0, ...) catches rounding errors at q = rK/4
p2 = plot(q, K / 2 .* (1 .+ w), color = gruen, lw = 3, label = "x₊* stable", xlims = (0, 21), legend = :bottomright,
          xlabel = "Catch quota q (1000 t/year)", title = "bifurcation diagram", titlefontsize = 10)
plot!(p2, q, K / 2 .* (1 .- w), ls = :dash, color = gruen, lw = 2, label = "x₋* unstable"); scatter!(p2, [12.5], [50], color = :black, label = "")
for qq in (8, 12.5)
    ww = sqrt(max(0, 1 - 4qq / (r * K)))
    @printf("q = %g: x_- = %.2f,  x_+ = %.2f\n", qq, K / 2 * (1 - ww), K / 2 * (1 + ww))
end
@printf("largest catch quota (MSY): q = rK/4 = %g\n", r * K / 4)
display(plot(p1, p2, layout = (1, 2), size = (900, 420)))

Gene switch of the lac operon

dX/dt = (a + X2)/(1 + X2) − r X

For 0.28 < r < 0.51 there are two stable states, “off” and “on”. The program determines them as roots of a polynomial and computes the turning points of the hysteresis curve.

# dX/dt = (a + X^2)/(1 + X^2) - r X with a = 0.02; left import and degradation for r = 0.4, right X* as a function of r (hysteresis)
# (c) 2026 Philipp Kügler · Program for the book "Dynamical Systems in the Life Sciences" · MIT License (see LICENSE)
using Printf, Plots
using LinearAlgebra

a = 0.02
imp(X) = (a + X^2) / (1 + X^2)
X = range(0, 3, length = 400); r = 0.4
p1 = plot(X, imp.(X), color = RGB(0, 0.447, 0.741), lw = 2.5, label = "Import (a + X²)/(1 + X²)", legend = :topleft, xlabel = "X")
plot!(p1, X, r .* X, ls = :dash, color = RGB(0.64, 0.08, 0.18), lw = 2, label = "Degradation r X, r = 0.4")
# steady state: (a + X^2) = r X (1 + X^2), i.e. -r X^3 + X^2 - r X + a = 0 (coefficients in ascending order)
# roots as eigenvalues of the companion matrix of X^3 - X^2/r + X - a/r
B = [1/r -1 a/r; 1 0 0; 0 1 0]
xs = sort(real.(eigvals(B)))
scatter!(p1, xs, r .* xs, color = [:black, :white, :black], msc = :black, label = "")
println("r = 0.4: X* = ", join([@sprintf("%.3f", x) for x in xs], "  "), "  (off, threshold, on)")
# bifurcation diagram: each X* belongs to r = Import(X*)/X*
Xs = range(0.005, 4, length = 4000); R = imp.(Xs) ./ Xs
i1 = argmin(ifelse.(Xs .< 0.5, R, Inf))              # turning points of the curve: smallest r on the lower branch,
i2 = argmax(ifelse.((Xs .> 0.5) .& (Xs .< 2), R, 0.0))   # largest r on the middle branch
gruen = RGB(0, 0.39, 0)
p2 = plot(R[1:i1], Xs[1:i1], color = gruen, lw = 3, legend = false, xlims = (0.1, 0.82), ylims = (-0.1, 3.2), xlabel = "Degradation rate r", ylabel = "X*")
plot!(p2, R[i1:i2], Xs[i1:i2], ls = :dash, color = gruen, lw = 2)
plot!(p2, R[i2:end], Xs[i2:end], color = gruen, lw = 3)
@printf("bistable for %.2f < r < %.2f\n", R[i1], R[i2])
display(plot(p1, p2, layout = (1, 2), size = (900, 420)))
